# Contributing

Thanks for your interest in contributing!

## First-time contributor quick start
1. Fork the repository.
2. Create a new branch for your change.
3. Keep your pull request focused on one small improvement.
4. Add or update tests when behavior changes.
5. Run tests locally with `pytest`.
6. Open a pull request and describe what changed and why.

## Tips
- Keep code easy to read.
- Ask questions in the pull request if anything is unclear.
- Be respectful and constructive in reviews.
